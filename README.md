# Kivara

Una maqueta adaptable de una app de outfits para iPad y computadora.

## Publicación

El sitio está preparado para publicarse en GitHub Pages mediante GitHub Actions. Al subir el proyecto a la rama `main`, el flujo de `.github/workflows/pages.yml` publicará los archivos estáticos.

La versión actual es una maqueta: las prendas agregadas y las fotos se mantienen solo durante la sesión del navegador. Todavía no hay cuenta de usuario ni almacenamiento permanente.
